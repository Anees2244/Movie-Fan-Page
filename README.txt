DEAD POETS SOCIETY - MOVIE FAN PAGE

FILES
- index.html: Home page
- characters.html: Characters page
- gallery.html: Movie gallery
- style.css: Shared styling for all pages
- images/: Local JPG images used by the website

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the extracted Dead-Poets-Society folder in VS Code.
3. Open index.html in a browser (or use Live Server).
4. Use the navigation links to visit Home, Characters, and Gallery.

IMAGES
All website image references now point to local .jpg files in the images folder.
The character and scene illustrations are newly created cinematic visual artwork, not official film publicity stills. The final gallery scene uses the image supplied with the original assignment. Keep the images folder beside the HTML files so all images load correctly.
